# Required for the Groq API path (config.py's default provider for both
# primary and fallback models). NOT required if you only ever run with
# Gemini models (PRIMARY_MODEL/FALLBACK_MODEL set to a "gemini-*" name,
# as this project currently is) -- llm_engine._call_gemini() talks to the
# Gemini REST API with plain stdlib urllib, no SDK needed.

# Optional -- only needed if you set FALLBACK_PROVIDER=openai in your .env

# openai>=1.0.0

# Optional -- nicer test output. test_suite.py runs fine with plain
# `python -m unittest test_suite -v` without this; uncomment if you'd
# rather use `pytest test_suite.py -v`.
# pytest>=7.0.0

# NOTE: this project does NOT use python-dotenv -- config.py reads

#        export $(grep -v '^#' .env | xargs)      (macOS/Linux)
